# Карта объектов «Линкор» — обновление

Эта версия добавляет:

1. Проверку нового адреса по логистике.
2. Переключение между обычной картой Москвы и схемой метро.
3. Фирменное оформление и логотип «Линкор».
4. Компактную схему метро: МЦД-3 и МЦД-4 скрыты по умолчанию и включаются отдельным переключателем.
5. Актуальную карту зданий и поиск адресов через официальный API 2ГИС.
6. Убрана иконка флага из служебной подписи Leaflet; указание авторства Leaflet и поставщика карты сохраняется.
7. Выбор маршрута до ближайшего действующего объекта: на машине, пешком или на общественном транспорте.

## Как обновить сайт на GitHub

Замените в репозитории файл `app.py`, замените `requirements.txt` и добавьте папку `assets` с файлом `logo_linkor.png`.

Файл `objects.xlsx` не заменяйте — приложение продолжит использовать вашу действующую таблицу.

Структура репозитория должна быть такой:

```text
moscow-objects-map/
├── app.py
├── objects.xlsx
├── requirements.txt
└── assets/
    └── logo_linkor.png
```

После загрузки файлов нажмите **Commit changes**. Streamlit автоматически перезапустит приложение; постоянная ссылка не изменится.

## Подключение актуальной карты 2ГИС

Для карты зданий нужен API-ключ. Он не должен храниться в GitHub.

1. Откройте [Менеджер платформы 2ГИС](https://platform.2gis.ru/).
2. Создайте демо-ключ или подписку и подключите к ключу **Raster Tiles API**, **Geocoder API** и **Routing API** (включая маршруты общественного транспорта).
3. В Streamlit Community Cloud откройте приложение → **Settings → Secrets**.
4. Добавьте:

```toml
DGIS_API_KEY = "ваш_ключ_2ГИС"
```

5. Сохраните настройки и перезапустите приложение.

Проверьте подпись внизу карты: при активном ключе там будет **© 2ГИС**, а не **© OpenStreetMap contributors**. Если видна OpenStreetMap, сайт не получил ключ из Secrets. Файл `secrets.toml.example` в архиве — только образец, запись ключа в него или в GitHub не подключает 2ГИС.

Если ключ отсутствует или сервис временно недоступен, сайт автоматически использует резервную карту OpenStreetMap. Маркеры и таблица объектов при этом не пропадают.

## Как работает оценка нового адреса

- адрес здания и его координаты определяются через 2ГИС;
- программа находит несколько ближайших действующих объектов;
- сотрудник выбирает способ передвижения и нажимает **Проверить**;
- для нескольких ближайших кандидатов 2ГИС рассчитывает время и расстояние выбранного маршрута; на карте отображается его линия;
- для автомобиля при недоступности маршрутизации 2ГИС используется резервный автомобильный маршрут OSRM;
- если выбранный маршрут недоступен, приложение сообщает об этом, показывает расстояние по прямой и не подменяет время в пути расчётом для другого транспорта;
- итоговая категория рассчитывается по времени до ближайшего объекта и плотности объектов рядом.

Пороговые значения можно менять в левой панели в разделе **Правила логистики**.

## Важно

Расчёт является предварительной логистической оценкой, а не коммерческим решением. Пробки, график инженеров, состав работ и допуски объекта он не учитывает.
