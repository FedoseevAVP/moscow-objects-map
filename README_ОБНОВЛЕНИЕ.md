# Карта объектов «Линкор» — обновление

Эта версия добавляет:

1. Проверку нового адреса по логистике.
2. Переключение между обычной картой Москвы и схемой метро.
3. Фирменное оформление и логотип «Линкор».

## Как обновить сайт на GitHub

Замените в репозитории файл `app.py`, замените `requirements.txt` и добавьте папку `assets` с файлом `logo_linkor.png`.

Файл `objects.xlsx` не заменяйте — приложение продолжит использовать вашу действующую таблицу.

Структура репозитория должна быть такой:

```text
moscow-objects-map/
├── app.py
├── objects.xlsx
├── requirements.txt
└── assets/
    └── logo_linkor.png
```

После загрузки файлов нажмите **Commit changes**. Streamlit автоматически перезапустит приложение; постоянная ссылка не изменится.

## Как работает оценка нового адреса

- адрес переводится в координаты через OpenStreetMap;
- программа находит несколько ближайших действующих объектов;
- для ближайших кандидатов запрашиваются время и расстояние по автомобильным дорогам;
- если маршрутизация временно недоступна, используется расстояние по прямой;
- итоговая категория рассчитывается по времени до ближайшего объекта и плотности объектов рядом.

Пороговые значения можно менять в левой панели в разделе **Правила логистики**.

## Важно

Расчёт является предварительной логистической оценкой, а не коммерческим решением. Пробки, график инженеров, состав работ и допуски объекта он не учитывает.
